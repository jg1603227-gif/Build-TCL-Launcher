TCL LAUNCHER 2.0 - PROJETO-FONTE PARA ANDROID TV

Alvo inicial: TCL 40S5K / Android TV 14
Application ID: br.com.tcllauncher

O QUE ESTA VERSAO IMPLEMENTA
- Interface escura com menu lateral.
- Tela inicial híbrida: destaque visual e acesso rápido a aplicativos.
- Lista de aplicativos que publicam uma atividade LAUNCHER ou LEANBACK_LAUNCHER.
- Categorias de vídeo e música por identificação simples de nome/pacote.
- Abertura de aplicativos pelo controle remoto (OK/Enter).
- Estados de foco para navegação com as setas.
- Relógio atualizado periodicamente.
- Acesso às configurações do Android.

LIMITES CONHECIDOS
- As áreas Filmes e séries e Música apenas filtram aplicativos instalados; não
  exibem catálogos, recomendações ou conteúdo de serviços de streaming.
- Alguns aplicativos podem não aparecer se o fabricante não expuser uma
  atividade de abertura compatível.
- A substituição da tela HOME depende de o firmware TCL permitir selecionar
  outro aplicativo como launcher padrão. O projeto não altera partições nem
  remove o launcher original.
- Este pacote contém código-fonte, não um APK compilado.

COMPILAR NA NUVEM PELO GITHUB
1. Extraia o ZIP e envie todos os arquivos para a raiz de um repositório GitHub.
2. Inclua a pasta oculta .github/workflows.
3. Abra a aba Actions e execute "Build TCL Launcher APK".
4. Baixe o artefato "TCL-Launcher-2.0-debug" quando a execução terminar.
5. Dentro do artefato estará app-debug.apk.

A compilação usa Java 17, Gradle 8.9, Android Gradle Plugin 8.7.3 e SDK 35.
Para desenvolvimento local, use Android Studio recente com JDK 17.
